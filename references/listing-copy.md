# 闲鱼代发文案规则与定价口径

## 一、文案骨架（照抄，改前先读本文件）

```
标题（30 字以内，描述第一行同时也是标题）
京东直发 <短型号> <容量/颜色>

正文
【价格】京东官方直发，在京东官方价基础上直接优惠 {N} 元：京东现价 ¥{jd}，本单 ¥{price}。
【为什么便宜】公司发的京东礼品卡用不完，折价套现，所以让利 {N} 元。不是翻新机、不是问题机、不是渠道货。
【发货】京东官方直发：你拍下后我在京东自营旗舰店下单，收货地址填你的，京东物流配送，
        运单号同步给你，京东 App 可查全程物流。
【注意】<仅 iPhone> 需当面签收并激活（京东平台要求），激活后即视为已使用。
【售后】非质量问题不退不换。质量问题请直接走京东官方售后（京东自营七天无理由/保修政策），
        我全程协助对接，售后结论以京东官方判定为准。
【正品】京东自营旗舰店，全新未拆封、原封未拆，可当面验机；收货请全程录像开箱。
【交易】只走闲鱼平台交易，不私下转账、不加微信、不脱离平台。
【其他】价格已经很实，谢绝还价；库存按拍下顺序，拍前先确认。

商品型号：<京东完整标题>
京东同款在售，可自行比价。
```

## 二、为什么这么写（每段的作用）

| 段落 | 作用 | 不做会怎样 |
|---|---|---|
| 【价格】 | 明示"优惠 N 元"和两个价格，消除"为什么便宜是不是有问题"的第一反应 | 买家比价后觉得你在骗人 |
| 【为什么便宜】 | 给出**可解释的合理来源**（礼品卡折价套现） | "低价=假货/翻新"的默认联想 |
| 【发货】 | 说清不是现货，是拍下后京东下单直发；给物流可查的信任点 | 买家以为你发货慢/没货 |
| 【售后】 | 事前把"不退不换 + 质量问题走京东官方"写死 | 事后纠纷时平台倾向买家 |
| 【正品】 | 自营店 + 未拆封 + 录像开箱，是可核对的事实描述 | 无法举证 |
| 【交易】 | 拒绝站外交易，规避电诈与违规 | 被判违规/被骗 |

## 三、绝对不要写

| 禁止 | 原因 |
|---|---|
| 「可开发票 / 提供发票 / 原封带票」 | 代发场景兑现不了；已实测被要求删除 |
| 「全新正品假一赔十」等无法自证的承诺 | 无法举证，纠纷时反而是把柄 |
| 微信 / QQ / 手机号 / 「私聊加V」 | 站外引流，直接违规 |
| 京东或其他平台的可点击链接 | 站外引流 |
| 「支持7天无理由」（若实际是质量问题才退） | 与【售后】自相矛盾，纠纷必输 |
| 绝对化用语（最低价/全网最低/第一） | 广告法风险 |

## 四、定价口径

```
闲鱼标价 = 京东价 − 200
实际到手 = 闲鱼标价 × (1 − 1.6%)   ← 鱼小铺服务费，按成交额计
```

**必须算进去的两个数**
1. 服务费 1.6%：¥12799 标价 → 扣 ¥204.78 → 到手 ¥12594.22
2. 京东价口径差：搜索页券后价可能比详情页标价低 300 左右

**倒挂检查**（写进上架前自检）：

```
到手价 ≥ 京东价 × 礼品卡折扣
例：京东 12999，95 折卡成本 12349，到手 12594 → 赚 245 ✅
    若标价按 11699-200=11499 → 到手 11313 < 12349 → 亏 1036 ❌
```

→ 用搜索价定价时必须确认：**这个搜索价是不是真实的京东成交价**。
不确定就加安全垫，宁高勿低。

## 五、标题写法

- 长度 ≤30 字符（超了闲鱼截断，关键词丢失）
- 结构：`京东直发 + 短型号 + 容量/规格`
- 例：`京东直发 iPhone18ProMax 512G 银色`
- 「京东直发」放最前：既是卖点也是**合规声明**（说明货源，降低诈骗误判）
- 不要堆砌关键词（易判违规、也影响可读性）

## 六、图片配置（发布时 6–9 张）

| 顺序 | 内容 | 来源 |
|---|---|---|
| 1 | 产品正面/背面主图（白底干净） | 品牌官网 |
| 2–3 | 不同角度 | 品牌官网 |
| 4 | 配色/材质特写 | 品牌官网 |
| 5 | 包装/配件（如有） | 品牌官网 |
| 6+ | 规格说明图（可自制白底文字图） | 自制 |

**不要**：京东主图（促销条+水印）、带其他平台 logo 的图、带价格的图。
